# ByteBay

ByteBay is a full-stack e-commerce application for modern technology products.

## Current Progress

- Created the React frontend with Vite
- Cleaned the default project structure
- Added the initial ByteBay landing page
- Prepared reusable component and screen folders

## Planned Features

- Product catalog
- Product details
- Shopping cart
- User authentication
- Checkout process
- PayPal payments
- Product reviews
- Admin dashboard
- Product and order management

## Technology Stack

- React
- Node.js
- Express
- MongoDB
- Redux Toolkit
